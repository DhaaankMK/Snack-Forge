# 🍔 SnackForge - AI Prompt & Payload Encrypter

> Uma ferramenta desktop moderna desenvolvida em Python e Tkinter para criptografar prompts de IA em arquivos protegidos `.ai-snack`, garantindo a integridade dos payloads e a preservação irrevogável dos créditos de autoria.

## 🚀 Principais Recursos
- **Interface Gráfica Moderna (GUI):** Desenvolvida com layout limpo, seletor de diretórios dinâmico e scroll integrado.
- **Sistema Anti-Impostor & System Override:** Injeção oculta de regras de comportamento e autoria dentro do payload codificado em Base64.
- **Compilação Segura:** Gerado de forma nativa e isolada para Windows (`.exe`) via PyInstaller, sem dependências externas complexas para o usuário final.
